CodeFixer

A focused Python code-quality agent that accepts one file or one folder, fixes safe issues automatically, and leaves business logic for human review.

Only input required

Provide the path to a Python file or folder.

C:\Projects\MyRiskModel
C:\Projects\MyRiskModel\model.py

What it does

CodeFixer scans the supplied target, checks Python quality, fixes safe mechanical issues, validates the result, and reports anything that needs human judgment.

Black

Consistent Python formatting and PEP 8-oriented formatting.

isort

Additional Python style and lint checks.

Mypy / Pyright

Bandit

Python security checks without exposing detected secrets.

Pylint

Additional code-quality and maintainability analysis.

Radon

Complexity analysis for functions and modules.

Safety model

Automatically fix

Formatting, import ordering, whitespace, unused imports and other clearly mechanical lint fixes.

Manual review

Mathematical calculations, pandas transformations, exception handling, algorithms, APIs, thresholds and business rules.

Designed for serious Python code

The agent is intentionally conservative around logic. This is particularly useful for financial, quantitative, statistical and risk-model code where a "cleaner" refactor can accidentally alter calculations.

Final report

After fixing, CodeFixer reports files scanned, fixes performed, tool results, remaining issues, modified files and whether any potential behavior-changing modification requires review.
