Python Environment Setup Agent

Give the agent a repository path. It prepares the Python virtual environment, installs requirements, handles optional packages, and validates the resulting environment.

What the agent does

01Repository detectionValidates the folder and inspects common Python project files.
02Virtual environmentCreates a local .venv, or another name you provide.
03DependenciesInstalls packages from requirements.txt.
04Extra packagesLets you add packages such as pyarrow, pandera, or plotly.
05ValidationRuns pip check and performs lightweight import validation.
06ReportReturns the Python version, environment path, packages and setup status.

Typical commands used by the agent

# Create environment
python -m venv .venv

# Upgrade packaging tools
.venv\Scripts\python.exe -m pip install --upgrade pip setuptools wheel

# Install requirements
.venv\Scripts\python.exe -m pip install -r requirements.txt

# Install additional packages
.venv\Scripts\python.exe -m pip install pyarrow pandera plotly

# Validate dependencies
.venv\Scripts\python.exe -m pip check

Safety behavior

Existing environments are not deleted automatically.
Application source code is not modified.
requirements.txt is not changed automatically.
The environment's own Python is used for pip operations.

Future extensions

The same agent can later be extended to detect Poetry, uv, Pipenv or Conda, configure the VS Code interpreter, run tests, create a .gitignore entry, generate requirements files, and perform a project smoke test.
